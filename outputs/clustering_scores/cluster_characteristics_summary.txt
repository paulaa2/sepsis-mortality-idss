Resumen de clusters - clustering_scores
======================================

Nota importante:
Este resumen describe los clusters guardados actualmente en la carpeta
"outputs/clustering_scores". La ejecucion se hizo con el preset "scores_only".
Si se vuelve a ejecutar el pipeline despues de corregir el ranking del mejor
modelo, el modelo seleccionado podria cambiar.

Descripcion general
-------------------
El enfoque "scores_only" usa principalmente variables agregadas de gravedad:
APSIII, APSIII_prob y los distintos scores fisiologicos y analiticos.
Por eso los clusters tienden a parecer una estratificacion por severidad mas
que fenotipos clinicos muy distintos.

Cluster 2
---------
- Tamano: 12.653 pacientes (23,65%)
- Perfil global: grupo de mayor gravedad dentro de esta solucion.
- Rasgos principales:
  * APSIII y APSIII_prob claramente elevados.
  * GCS_score alto, compatible con mayor gravedad neurologica dentro del score.
  * WBC_score y temp_score altos, lo que apunta a una mayor carga inflamatoria.
  * Tambien destaca por mayor severidad global del cuadro.
- Interpretacion:
  Este cluster representa el grupo de pacientes con mayor severidad agregada.
  Es el cluster que mejor encaja con una etiqueta tipo "high severity" o
  "alto riesgo clinico" dentro de una segmentacion basada en scores.

Cluster 0
---------
- Tamano: 8.450 pacientes (15,80%)
- Perfil global: grupo intermedio.
- Rasgos principales:
  * APSIII y APSIII_prob intermedios.
  * Temp_score, hematocrit_score y mbp_score algo por encima de la media.
  * Edad algo mayor que la del cluster de menor gravedad.
  * BUN_score discretamente elevado.
- Interpretacion:
  Este cluster parece recoger pacientes con gravedad moderada y con algunas
  alteraciones fisiologicas y analiticas, pero sin alcanzar la severidad del
  cluster 2. Encaja bien como grupo "intermedio".

Cluster 1
---------
- Tamano: 32.390 pacientes (60,55%)
- Perfil global: grupo de menor gravedad.
- Rasgos principales:
  * APSIII y APSIII_prob bajos.
  * Temp_score y WBC_score por debajo de la media.
  * GCS_score mas bajo, coherente con menor gravedad en este sistema de scores.
  * Es el cluster mayoritario de la cohorte.
- Interpretacion:
  Este cluster representa a los pacientes mas estables dentro del enfoque
  basado en scores. Es el candidato natural a grupo "low severity".

Conclusiones utiles para el trabajo
-----------------------------------
- Este clustering es facil de explicar porque ordena bien la cohorte en
  gravedad baja, media y alta.
- Es una opcion buena si se quiere una capa intermedia sencilla entre el
  modelo predictivo y la recomendacion del IDSS.
- Su punto debil es que describe menos "fenotipos" clinicos diferenciados y
  mas bien una escala de severidad.
